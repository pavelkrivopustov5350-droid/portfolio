# Портфолио · Project / Growth Lead

Одностраничный сайт-портфолио в тёмной сай-фай теме. Главная фишка — интерактивная
**карта связей**: проекты, каналы, команды и результаты как граф, где видно, что на
что влияет. Кейсы описываются в отдельных файлах-данных и открываются боковой панелью.

Стек: **Vite + React + TypeScript**, граф — `d3-force` + отрисовка на canvas.
Внешних рантайм-зависимостей на страницах нет (шрифты — Google Fonts).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — режим разработки
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
npm run typecheck  # проверка типов
```

Нужен Node 18+.

## Где править контент

Весь текст сайта — в `src/data/`. Больше нигде трогать не нужно.

| Файл | Что внутри |
| --- | --- |
| `src/data/profile.ts` | Имя, роль, питч на первом экране, навыки, опыт (таймлайн), контакты |
| `src/data/projects.ts` | `cases` — подробные кейсы; `graphNodes` / `graphLinks` — карта связей |
| `src/data/types.ts` | Описание всех полей (справочник, менять не обязательно) |

### Добавить кейс

1. В `src/data/projects.ts` добавь объект в массив `cases` (скопируй соседний как шаблон).
   Обязательные поля: `id`, `title`, `role`, `period`, `org`, `tagline`, `tags`,
   `metrics`, `blocks`. Необязательные: `related`, `links`, `accent`.
2. Кейс сразу появится в секции «Кейсы» и будет открываться по прямой ссылке
   `…/#/case/<id>`.

### Добавить узел на карту связей

1. Добавь объект в `graphNodes`:
   ```ts
   { id: "my-node", label: "Мой проект", kind: "project",
     caseId: "мой-кейс", metric: "+30% выручки",
     summary: "Короткое описание для тултипа." }
   ```
   `kind` — один из: `project` (ромб), `initiative`, `channel`, `team`, `outcome`
   (шестиугольник). Цвет берётся из типа.
2. Добавь связи в `graphLinks`:
   ```ts
   { source: "my-node", target: "ch-paid", kind: "drives", label: "подпись связи" }
   ```
   `kind` связи: `drives`, `depends`, `spawned`, `shares`, `informs` — влияет на стиль линии.
3. Если у узла есть `caseId`, клик по нему открывает кейс. Остальные узлы по клику
   подсвечивают свои связи.

### Поменять цвета / шрифты

`src/styles/theme.css` — все переменные темы (фон, акценты, свечение, типографика).
Цвета типов узлов графа — переменные `--kind-*` там же.

## Деплой

Сборка статическая, `base` = `./`, поэтому кладётся куда угодно.

- **GitHub Pages**: настроен через `.github/workflows/deploy.yml` — при каждом push
  в `main` собирается и публикуется на `https://<user>.github.io/portfolio/`.
  Первый раз: Settings → Pages → Source → **GitHub Actions** (либо workflow включит
  Pages сам при первом запуске).
- **Netlify / Vercel**: подключить репозиторий, build `npm run build`, publish `dist`.
- **Любой хостинг**: залить содержимое `dist/`.

## Структура

```
src/
  data/         контент (профиль, кейсы, граф)
  components/
    Backdrop        живой фон (частицы + радар-развёртка)
    Nav / Hero      шапка и первый экран
    GraphView/      карта связей (canvas + d3-force)
    CaseIndex       сетка карточек кейсов
    CasePanel       боковая панель с полным кейсом
    About / Timeline / Contact / Footer
    ui/             мелкие примитивы (Metric, Tag, GlitchText)
  hooks/          useHashRoute (ссылки на кейсы), useReveal (появление при скролле)
  lib/graph.ts    подготовка данных графа, размеры/цвета узлов
  styles/         theme.css + global.css
```

## Доступность и производительность

- Уважается `prefers-reduced-motion` — анимации фона и графа замирают.
- Граф settle-ится и останавливает симуляцию; перетаскивание/зум её будят.
- На узких экранах карта связей превращается в поверхность для перетаскивания,
  подписи узлов показываются по тапу.
